## `config.py`

Функций в этом файле нет. В нём заданы настройки: `BUF_SIZE` — размер буфера одного направления, `HS_RECV_SIZE` — размер чтения рукопожатия, `HANDSHAKE_TIMEOUT` и `CONNECT_TIMEOUT` — тайм-ауты рукопожатия и TCP-подключения, `DNS_TIMEOUT` и `DNS_ATTEMPTS` — тайм-аут и число попыток DNS, `LISTEN_BACKLOG` — размер очереди ожидающих подключений.

## `dns_message.py`

### `decode_hostname`

**Зачем нужна:** Пытается декодировать имя домена как ASCII. Если байты не ASCII, декодирует UTF-8 и преобразует имя в ASCII-представление IDNA. Ошибку декодирования или IDNA преобразования переводит в ValueError с сообщением bad hostname.

**Код:**

```python
def decode_hostname(raw):
    try:
        return raw.decode("ascii")
    except UnicodeDecodeError:
        try:
            return raw.decode("utf-8").encode("idna").decode("ascii")
        except UnicodeError as e:
            raise ValueError("bad hostname") from e
```

### `encode_name`

**Зачем нужна:** Кодирует доменное имя в DNS wire format: удаляет конечную точку, проверяет общую длину, разбивает имя на метки и добавляет перед каждой меткой её длину, а в конце — нулевой байт. Некорректные имена и метки вызывают ValueError.

**Код:**

```python
def encode_name(name):
    name = name.rstrip(".")
    if not name or len(name) > 253:
        raise ValueError("bad name")
    out = bytearray()
    for label in name.split("."):
        raw = label.encode("ascii")
        if not 1 <= len(raw) <= 63:
            raise ValueError("bad label")
        out.append(len(raw))
        out += raw
    out.append(0)
    return bytes(out)
```

### `build_query`

**Зачем нужна:** Собирает DNS-пакет запроса A-записи. В заголовке помещает идентификатор, флаг RD и число вопросов 1; затем добавляет закодированное имя, тип A и класс IN.

**Код:**

```python
def build_query(qid, qname_wire):
    return struct.pack("!HHHHHH", qid, 0x0100, 1, 0, 0, 0) + qname_wire + struct.pack("!HH", 1, 1)
```

### `read_name`

**Зачем нужна:** Читает доменное имя из DNS-пакета по смещению. Поддерживает DNS compression pointers: при переходе по указателю сохраняет позицию продолжения исходного поля. Переводит метки в нижний регистр, ограничивает переходы 32 прыжками и возвращает пару (имя, смещение после имени).

**Код:**

```python
def read_name(data, off):
    labels = []
    end = None
    jumps = 0
    while True:
        length = data[off]
        if length & 0xC0 == 0xC0:
            ptr = ((length & 0x3F) << 8) | data[off + 1]
            if end is None:
                end = off + 2
            off = ptr
            jumps += 1
            if jumps > 32:
                raise ValueError("compression loop")
        elif length == 0:
            if end is None:
                end = off + 1
            break
        else:
            labels.append(data[off + 1:off + 1 + length].decode("ascii", "replace").lower())
            off += 1 + length
    return ".".join(labels), end
```

### `parse_response`

**Зачем нужна:** Проверяет и разбирает DNS-ответ для ожидаемого имени. Отбрасывает короткий пакет, пакет без QR и ответы с неверным количеством вопросов или другим именем. При DNS RCODE возвращает пустой список; из секции ответов собирает IPv4 A-записи класса IN. Некорректную структуру также превращает в пустой список, а пакет не для этого запроса — в None.

**Код:**

```python
def parse_response(data, expected_name):
    if len(data) < 12:
        return None
    _, flags, qd, an, _, _ = struct.unpack("!HHHHHH", data[:12])
    if not flags & 0x8000:
        return None
    try:
        if qd != 1:
            return None
        name, off = read_name(data, 12)
        off += 4
        if name != expected_name:
            return None
        if flags & 0x000F:
            return []
        addrs = []
        for _ in range(an):
            _, off = read_name(data, off)
            rtype, rclass, _ttl, rdlen = struct.unpack("!HHIH", data[off:off + 10])
            off += 10
            rdata = data[off:off + rdlen]
            off += rdlen
            if rtype == 1 and rclass == 1 and rdlen == 4 and len(rdata) == 4:
                addrs.append(socket.inet_ntoa(rdata))
        return addrs
    except (IndexError, struct.error, ValueError):
        return []
```

## `errors.py`

### `rep_for_errno`

**Зачем нужна:** Преобразует код системной ошибки сокета в REP-код SOCKS5: отказ соединения, недоступная сеть, недоступный узел или общий сбой. Наборы кодов для сети и узла заданы выше в модуле.

**Код:**

```python
def rep_for_errno(err):
    if err == errno.ECONNREFUSED:
        return REP_REFUSED
    if err in _NET_ERRS:
        return REP_NETWORK
    if err in _HOST_ERRS:
        return REP_HOST
    return REP_FAIL
```

## `main.py`

### `main`

**Зачем нужна:** Точка входа CLI. Проверяет число аргументов и диапазон порта, выбирает DNS-резолвер (переданный пользователем или системный), создаёт Proxy и запускает цикл. Ошибки аргументов печатает в stderr и возвращает код 2; Ctrl+C завершает работу без traceback.

**Код:**

```python
def main():
    if len(sys.argv) not in (2, 3):
        print("Использование: main.py <port> [dns_ip:port]", file=sys.stderr)
        return 2
    try:
        port = int(sys.argv[1])
        if not 1 <= port <= 65535:
            raise ValueError
    except ValueError:
        print("Некорректный порт", file=sys.stderr)
        return 2
    if len(sys.argv) == 3:
        try:
            resolver = parse_hostport(sys.argv[2])
        except ValueError:
            print("DNS-резолвер должен быть в формате IPv4:port", file=sys.stderr)
            return 2
    else:
        resolver = system_resolver()
    proxy = Proxy(port, resolver)
    print(f"SOCKS5-прокси слушает порт {port}, DNS: {resolver[0]}:{resolver[1]}", file=sys.stderr)
    try:
        proxy.run()
    except KeyboardInterrupt:
        pass
    return 0
```

## `proxy.py`

### `Proxy.__init__`

**Зачем нужна:** Настраивает прокси: сохраняет адрес резолвера, создаёт селектор и таймеры, открывает TCP-сокет для клиентов и UDP-сокет для DNS. Сокеты переводятся в неблокирующий режим; слушающий TCP-сокет и DNS-сокет регистрируются в селекторе.

**Код:**

```python
    def __init__(self, port, resolver):
        self.resolver = resolver
        self.sel = selectors.DefaultSelector()
        self.timers = Timers()
        self.pending = {}

        self.lsock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.lsock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        self.lsock.bind(("0.0.0.0", port))
        self.lsock.listen(config.LISTEN_BACKLOG)
        self.lsock.setblocking(False)
        self.sel.register(self.lsock, EV_R, _LISTEN)

        self.dsock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        self.dsock.setblocking(False)
        self.sel.register(self.dsock, EV_R, _DNS)
```

### `Proxy.run`

**Зачем нужна:** Главный цикл событий. Ждёт события селектора не дольше ближайшего таймера, направляет события слушающего сокета, DNS-сокета и сокетов сессий в соответствующие обработчики. После обработки событий запускает обработку истёкших таймеров.

**Код:**

```python
    def run(self):
        while True:
            for key, mask in self.sel.select(self.timers.next_timeout()):
                data = key.data
                if data is _LISTEN:
                    self.on_accept()
                elif data is _DNS:
                    self.on_dns()
                else:
                    s, is_client = data
                    if s.closed:
                        continue
                    if is_client:
                        self.on_client(s, mask)
                    else:
                        self.on_remote(s, mask)
            for s in self.timers.pop_expired():
                self.on_timeout(s)
```

### `Proxy.on_timeout`

**Зачем нужна:** Обрабатывает тайм-аут в зависимости от состояния сессии. На рукопожатии закрывает соединение; при DNS повторяет запрос до лимита, затем отвечает REP_HOST; при подключении к серверу считает адрес неудачным и пробует следующий.

**Код:**

```python
    def on_timeout(self, s):
        if s.state in (GREETING, REQUEST):
            self.close(s)
        elif s.state == RESOLVING:
            if s.attempts < config.DNS_ATTEMPTS:
                self.send_dns(s)
            else:
                self.pending.pop(s.dns_id, None)
                s.dns_id = None
                self.reply_error(s, socks5.REP_HOST)
        elif s.state == CONNECTING:
            s.last_rep = socks5.REP_HOST
            self.drop_remote(s)
            self.connect_next(s)
```

### `Proxy.on_accept`

**Зачем нужна:** Принимает до 64 ожидающих подключений за один проход. Для каждого клиента включает неблокирующий режим, по возможности задаёт TCP_NODELAY, создаёт Session, ставит тайм-аут рукопожатия и обновляет подписки селектора. Если очередь пуста или accept завершился ошибкой, заканчивает текущий проход.

**Код:**

```python
    def on_accept(self):
        for _ in range(64):
            try:
                conn, _ = self.lsock.accept()
            except OSError:
                return
            conn.setblocking(False)
            try:
                conn.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)
            except OSError:
                pass
            s = Session(conn)
            self.timers.set(s, config.HANDSHAKE_TIMEOUT)
            self.update(s)
```

### `Proxy.client_events`

**Зачем нужна:** Вычисляет события селектора для клиентского сокета. Чтение нужно во время greeting/request, а в RELAY — пока нет EOF и буфер клиент→сервер не заполнен. Запись нужна, когда накоплены данные для отправки клиенту.

**Код:**

```python
    @staticmethod
    def client_events(s):
        ev = 0
        if s.state in (GREETING, REQUEST):
            ev |= EV_R
        elif s.state == RELAY and not s.c_eof and len(s.c2r) < config.BUF_SIZE:
            ev |= EV_R
        if s.r2c:
            ev |= EV_W
        return ev
```

### `Proxy.remote_events`

**Зачем нужна:** Вычисляет события для удалённого сокета. Пока он не создан, событий нет; во время CONNECTING ожидается запись, чтобы узнать результат подключения. В RELAY чтение включается при наличии места в буфере сервер→клиент, запись — при данных в буфере клиент→сервер.

**Код:**

```python
    @staticmethod
    def remote_events(s):
        if s.rsock is None:
            return 0
        if s.state == CONNECTING:
            return EV_W
        ev = 0
        if s.state == RELAY:
            if not s.r_eof and len(s.r2c) < config.BUF_SIZE:
                ev |= EV_R
            if s.c2r:
                ev |= EV_W
        return ev
```

### `Proxy._sync`

**Зачем нужна:** Синхронизирует регистрацию сокета с селектором. Если набор событий не изменился, ничего не делает; если новый набор пуст, снимает сокет с регистрации; иначе регистрирует или изменяет регистрацию. Возвращает актуальную маску событий.

**Код:**

```python
    def _sync(self, sock, cur, want, data):
        if want == cur:
            return cur
        if want == 0:
            self.sel.unregister(sock)
        elif cur == 0:
            self.sel.register(sock, want, data)
        else:
            self.sel.modify(sock, want, data)
        return want
```

### `Proxy.update`

**Зачем нужна:** Пересчитывает и применяет подписки селектора для обоих сокетов сессии. Закрытые сессии игнорируются. Контекст регистрации хранит сессию и признак, является ли сокет клиентским.

**Код:**

```python
    def update(self, s):
        if s.closed:
            return
        s.cmask = self._sync(s.csock, s.cmask, self.client_events(s), (s, True))
        if s.rsock is not None:
            s.rmask = self._sync(s.rsock, s.rmask, self.remote_events(s), (s, False))
```

### `Proxy.drop_remote`

**Зачем нужна:** Снимает удалённый сокет с селектора, если он зарегистрирован, закрывает его и сбрасывает ссылку и маску. Повторные ошибки снятия регистрации и закрытия игнорируются.

**Код:**

```python
    def drop_remote(self, s):
        if s.rsock is None:
            return
        if s.rmask:
            try:
                self.sel.unregister(s.rsock)
            except (KeyError, ValueError):
                pass
        s.rmask = 0
        try:
            s.rsock.close()
        except OSError:
            pass
        s.rsock = None
```

### `Proxy.close`

**Зачем нужна:** Закрывает сессию один раз. Помечает её закрытой, отменяет таймер, удаляет ожидающий DNS-запрос, закрывает удалённый и клиентский сокеты, снимает клиентский сокет с селектора и очищает буферы.

**Код:**

```python
    def close(self, s):
        if s.closed:
            return
        s.closed = True
        self.timers.cancel(s)
        if s.dns_id is not None:
            self.pending.pop(s.dns_id, None)
        self.drop_remote(s)
        if s.cmask:
            try:
                self.sel.unregister(s.csock)
            except (KeyError, ValueError):
                pass
        s.cmask = 0
        try:
            s.csock.close()
        except OSError:
            pass
        s.c2r.clear()
        s.r2c.clear()
```

### `Proxy.on_client`

**Зачем нужна:** Обрабатывает событие клиентского сокета: при READ вызывает обработчик рукопожатия или читает данные в режиме RELAY. Если сессия ещё открыта, запускает progress(), чтобы отправить накопившиеся данные и обновить регистрации.

**Код:**

```python
    def on_client(self, s, mask):
        if mask & EV_R:
            if s.state in (GREETING, REQUEST):
                self.read_handshake(s)
            elif s.state == RELAY:
                self.relay_read(s, True)
        if s.closed:
            return
        self.progress(s)
```

### `Proxy.on_remote`

**Зачем нужна:** Обрабатывает событие удалённого сокета. В CONNECTING проверяет результат подключения и сразу возвращается. В RELAY при READ читает серверные данные; затем для открытой сессии запускает progress().

**Код:**

```python
    def on_remote(self, s, mask):
        if s.state == CONNECTING:
            self.finish_connect(s)
            return
        if s.state == RELAY and mask & EV_R:
            self.relay_read(s, False)
        if s.closed:
            return
        self.progress(s)
```

### `Proxy.read_handshake`

**Зачем нужна:** Читает порцию данных от клиента в буфер рукопожатия и вызывает разбор. Временную нехватку данных оставляет на следующий вызов; ошибку чтения или EOF обрабатывает закрытием сессии.

**Код:**

```python
    def read_handshake(self, s):
        try:
            data = s.csock.recv(config.HS_RECV_SIZE)
        except (BlockingIOError, InterruptedError):
            return
        except OSError:
            self.close(s)
            return
        if not data:
            self.close(s)
            return
        s.hs.extend(data)
        self.parse_handshake(s)
```

### `Proxy.parse_handshake`

**Зачем нужна:** Последовательно разбирает greeting и SOCKS request из буфера. После greeting ставит ответ в очередь и переходит к REQUEST, если согласована аутентификация без пароля. Ошибку протокола без REP приводит к закрытию, с REP — к ответу. После полного CONNECT сохраняет возможные данные, пришедшие за запросом, и начинает подключение.

**Код:**

```python
    def parse_handshake(self, s):
        hs = s.hs
        try:
            if s.state == GREETING:
                res = socks5.parse_greeting(hs)
                if res is None:
                    return
                used, no_auth_ok = res
                del hs[:used]
                s.r2c.extend(socks5.greeting_reply(no_auth_ok))
                if not no_auth_ok:
                    s.state = CLOSING
                    self.timers.cancel(s)
                    return
                s.state = REQUEST
            res = socks5.parse_request(hs)
            if res is None:
                return
        except socks5.ProtocolError as e:
            if e.rep is None:
                self.close(s)
            else:
                self.reply_error(s, e.rep)
            return
        used, atyp, host, s.port = res
        del hs[:used]
        s.c2r.extend(hs)
        hs.clear()
        self.start_connect(s, atyp, host)
```

### `Proxy.reply_error`

**Зачем нужна:** Готовит ошибочный SOCKS5-ответ: отменяет таймер, закрывает удалённый сокет, помещает ответ в буфер клиенту, переводит сессию в CLOSING и запускает progress() для отправки ответа и закрытия.

**Код:**

```python
    def reply_error(self, s, rep):
        if s.closed:
            return
        self.timers.cancel(s)
        self.drop_remote(s)
        s.r2c.extend(socks5.build_reply(rep))
        s.state = CLOSING
        self.progress(s)
```

### `Proxy.start_connect`

**Зачем нужна:** Начинает подключение к адресу из SOCKS request. Для IPv4 сразу готовит список адресов. Для домена декодирует имя; если оно на самом деле IPv4-литерал, DNS пропускается. Иначе кодирует DNS-имя, запоминает ожидаемые имя и идентификатор запроса, переводит сессию в RESOLVING и отправляет DNS-запрос.

**Код:**

```python
    def start_connect(self, s, atyp, host):
        if atyp == socks5.ATYP_IPV4:
            s.addrs = [host]
            self.connect_next(s)
            return
        try:
            name = dns_message.decode_hostname(host)
        except ValueError:
            self.reply_error(s, socks5.REP_HOST)
            return
        try:
            s.addrs = [str(ipaddress.IPv4Address(name))]
            self.connect_next(s)
            return
        except ValueError:
            pass
        try:
            s.qwire = dns_message.encode_name(name)
        except (ValueError, UnicodeError):
            self.reply_error(s, socks5.REP_HOST)
            return
        s.qname = name.rstrip(".").lower()
        s.state = RESOLVING
        s.attempts = 0
        while True:
            qid = random.getrandbits(16)
            if qid not in self.pending:
                break
        s.dns_id = qid
        self.pending[qid] = s
        self.update(s)
        self.send_dns(s)
```

### `Proxy.send_dns`

**Зачем нужна:** Увеличивает счётчик попыток и отправляет DNS-запрос через общий UDP-сокет. Ошибку отправки не считает немедленным отказом: ставит таймер, после которого запрос можно повторить.

**Код:**

```python
    def send_dns(self, s):
        s.attempts += 1
        try:
            self.dsock.sendto(dns_message.build_query(s.dns_id, s.qwire), self.resolver)
        except OSError:
            pass
        self.timers.set(s, config.DNS_TIMEOUT)
```

### `Proxy.on_dns`

**Зачем нужна:** Читает до 256 UDP-пакетов за проход. Проверяет источник, наличие идентификатора и ожидающую DNS-сессию; разбирает пакет относительно ожидаемого имени. Неподходящие пакеты пропускает. При ответе снимает запрос и таймер; пустой результат даёт REP_HOST, адреса передаются в процедуру подключения.

**Код:**

```python
    def on_dns(self):
        for _ in range(256):
            try:
                data, addr = self.dsock.recvfrom(4096)
            except (BlockingIOError, InterruptedError):
                return
            except ConnectionError:
                continue
            except OSError:
                return
            if addr != self.resolver or len(data) < 2:
                continue
            (qid,) = struct.unpack("!H", data[:2])
            s = self.pending.get(qid)
            if s is None or s.closed or s.state != RESOLVING:
                continue
            addrs = dns_message.parse_response(data, s.qname)
            if addrs is None:
                continue
            del self.pending[qid]
            s.dns_id = None
            self.timers.cancel(s)
            if not addrs:
                self.reply_error(s, socks5.REP_HOST)
                continue
            s.addrs = addrs
            self.connect_next(s)
```

### `Proxy.connect_next`

**Зачем нужна:** Пробует адреса назначения по очереди. Для каждого создаёт неблокирующий TCP-сокет с TCP_NODELAY и вызывает connect_ex. При немедленном успехе начинает RELAY; при асинхронном подключении переводит сессию в CONNECTING и ставит таймер; при ошибке сохраняет REP и пробует следующий адрес. Если адресов не осталось, отвечает последней ошибкой.

**Код:**

```python
    def connect_next(self, s):
        while s.addrs:
            ip = s.addrs.pop(0)
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.setblocking(False)
            try:
                sock.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)
            except OSError:
                pass
            try:
                err = sock.connect_ex((ip, s.port))
            except OSError as e:
                err = e.errno or errno.EIO
            if err == 0:
                s.rsock = sock
                self.connected(s)
                return
            if err in CONNECT_IN_PROGRESS:
                s.rsock = sock
                s.state = CONNECTING
                self.timers.set(s, config.CONNECT_TIMEOUT)
                self.update(s)
                return
            s.last_rep = rep_for_errno(err)
            sock.close()
        self.reply_error(s, s.last_rep)
```

### `Proxy.finish_connect`

**Зачем нужна:** Получает итог асинхронного connect через SO_ERROR. При успехе вызывает connected(); при ошибке сохраняет соответствующий REP, закрывает удалённый сокет и пробует следующий адрес.

**Код:**

```python
    def finish_connect(self, s):
        try:
            err = s.rsock.getsockopt(socket.SOL_SOCKET, socket.SO_ERROR)
        except OSError as e:
            err = e.errno or errno.EIO
        if err == 0:
            self.connected(s)
        else:
            s.last_rep = rep_for_errno(err)
            self.drop_remote(s)
            self.connect_next(s)
```

### `Proxy.connected`

**Зачем нужна:** Формирует успешный ответ SOCKS5 с локальным адресом и портом исходящего сокета. Если получить их нельзя, использует адрес и порт по умолчанию. Затем переводит сессию в RELAY, отменяет таймер подключения и запускает progress().

**Код:**

```python
    def connected(self, s):
        try:
            host, port = s.rsock.getsockname()[:2]
            reply = socks5.build_reply(socks5.REP_OK, host, port)
        except (OSError, ValueError):
            reply = socks5.build_reply(socks5.REP_OK)
        s.r2c.extend(reply)
        s.state = RELAY
        self.timers.cancel(s)
        self.progress(s)
```

### `Proxy.relay_read`

**Зачем нужна:** Читает данные из одного конца туннеля в соответствующий буфер, если буфер не достиг BUF_SIZE. Временные ошибки чтения игнорирует до следующего события; другие ошибки закрывают сессию. Пустое чтение отмечает EOF со стороны клиента или сервера.

**Код:**

```python
    def relay_read(self, s, from_client):
        src, buf = (s.csock, s.c2r) if from_client else (s.rsock, s.r2c)
        if len(buf) >= config.BUF_SIZE:
            return
        try:
            data = src.recv(config.BUF_SIZE)
        except (BlockingIOError, InterruptedError):
            return
        except OSError:
            self.close(s)
            return
        if data:
            buf.extend(data)
        elif from_client:
            s.c_eof = True
        else:
            s.r_eof = True
```

### `Proxy.flush`

**Зачем нужна:** Пытается отправить содержимое одного буфера в соответствующий сокет. Если буфер пуст или сокета нет, ничего не делает. При временной ошибке ждёт следующего события, при постоянной закрывает сессию; отправленную часть удаляет из буфера.

**Код:**

```python
    def flush(self, s, to_client):
        sock, buf = (s.csock, s.r2c) if to_client else (s.rsock, s.c2r)
        if not buf or sock is None:
            return
        try:
            n = sock.send(buf)
        except (BlockingIOError, InterruptedError):
            return
        except OSError:
            self.close(s)
            return
        del buf[:n]
```

### `Proxy._shutdown_wr`

**Зачем нужна:** Вызывает shutdown(SHUT_WR) для сокета, чтобы завершить передачу в одном направлении, сохранив возможность чтения. Ошибки shutdown игнорируются.

**Код:**

```python
    @staticmethod
    def _shutdown_wr(sock):

            sock.shutdown(socket.SHUT_WR)
        except OSError:
            pass
```

### `Proxy.progress`

**Зачем нужна:** Продвигает сессию после события: сначала пытается отправить клиенту. В RELAY отправляет данные серверу, выполняет half-close после опустошения соответствующих буферов и закрывает сессию, когда обе стороны прислали EOF и данных больше нет. В CLOSING закрывает соединение после отправки ответа. В конце обновляет селектор.

**Код:**

```python
    def progress(self, s):
        if s.closed:
            return
        self.flush(s, True)
        if s.closed:
            return
        if s.state == RELAY:
            self.flush(s, False)
            if s.closed:
                return
            if s.c_eof and not s.c2r and not s.r_shut:
                s.r_shut = True
                self._shutdown_wr(s.rsock)
            if s.r_eof and not s.r2c and not s.c_shut:
                s.c_shut = True
                self._shutdown_wr(s.csock)
            if s.c_eof and s.r_eof and not s.c2r and not s.r2c:
                self.close(s)
                return
        elif s.state == CLOSING and not s.r2c:
            self._shutdown_wr(s.csock)
            self.close(s)
            return
        self.update(s)
```

## `resolver_config.py`

### `parse_hostport`

**Зачем нужна:** Разбирает строку адреса DNS-резолвера формата IPv4:port. Отделяет последнюю часть после двоеточия как порт, проверяет IPv4 через ipaddress и диапазон порта 1–65535. При неверном формате преобразование выбрасывает ValueError.

**Код:**

```python
def parse_hostport(text):
    host, _, port = text.rpartition(":")
    ipaddress.IPv4Address(host)
    port = int(port)
    if not 1 <= port <= 65535:
        raise ValueError("port")
    return host, port
```

### `system_resolver`

**Зачем нужна:** Ищет адрес системного DNS. Сначала читает IPv4 nameserver из /etc/resolv.conf. На Windows при неудаче запускает ipconfig /all и ищет IPv4 после DNS. Если определить адрес не получилось, печатает предупреждение и возвращает 8.8.8.8:53.

**Код:**

```python
def system_resolver():
    try:
        with open("/etc/resolv.conf") as f:
            for line in f:
                parts = line.split()
                if len(parts) >= 2 and parts[0] == "nameserver":
                    try:
                        return str(ipaddress.IPv4Address(parts[1])), 53
                    except ValueError:
                        continue
    except OSError:
        pass
    if os.name == "nt":
        try:
            out = subprocess.run(["ipconfig", "/all"], capture_output=True, text=True,
                                 timeout=5, errors="replace").stdout
            m = re.search(r"DNS[^:\n]*:\s*(\d+\.\d+\.\d+\.\d+)", out)
            if m:
                return m.group(1), 53
        except Exception:
            pass
    print("Не удалось определить системный DNS, используется 8.8.8.8:53", file=sys.stderr)
    return "8.8.8.8", 53
```

### `parse_greeting`

**Зачем нужна:** Разбирает клиентское приветствие SOCKS5. Если данных меньше минимальных или ещё не пришли все методы, возвращает None. Проверяет версию, иначе поднимает ProtocolError. При полном сообщении возвращает число использованных байтов и флаг, предлагал ли клиент NO AUTHENTICATION REQUIRED.

**Код:**

```python
def parse_greeting(buf):
    if len(buf) < 2:
        return None
    if buf[0] != VER:
        raise ProtocolError()
    n = buf[1]
    if len(buf) < 2 + n:
        return None
    return 2 + n, METHOD_NO_AUTH in bytes(buf[2:2 + n])
```

### `parse_request`

**Зачем нужна:** Разбирает запрос SOCKS5 CONNECT. Проверяет длину заголовка, версию и команду; определяет длину адреса по ATYP (IPv4 или домен), ждёт недостающие байты, извлекает порт и адрес. Для неподдерживаемой команды/типа адреса поднимает ProtocolError с REP-кодом.

**Код:**

```python
def parse_request(buf):
    if len(buf) < 4:
        return None
    if buf[0] != VER:
        raise ProtocolError()
    if buf[1] != CMD_CONNECT:
        raise ProtocolError(REP_CMD)
    atyp = buf[3]
    if atyp == ATYP_IPV4:
        need = 10
    elif atyp == ATYP_DOMAIN:
        if len(buf) < 5:
            return None
        need = 7 + buf[4]
    else:
        raise ProtocolError(REP_ATYP)
    if len(buf) < need:
        return None
    (port,) = struct.unpack("!H", bytes(buf[need - 2:need]))
    if atyp == ATYP_IPV4:
        host = socket.inet_ntoa(bytes(buf[4:8]))
    else:
        host = bytes(buf[5:5 + buf[4]])
    return need, atyp, host, port
```

## `timers.py`

### `Timers.__init__`

**Зачем нужна:** Создаёт пустую кучу таймеров и счётчик последовательности. Последовательность помогает различать записи с одинаковым временем срабатывания.

**Код:**

```python
    def __init__(self):
        self._heap = []
        self._seq = itertools.count()
```

### `Timers.set`

**Зачем нужна:** Назначает сессии таймер. Увеличивает её поколение, вычисляет абсолютное время через монотонные часы и добавляет запись (время, порядковый номер, сессия, поколение) в кучу. Старые записи таким образом становятся устаревшими.

**Код:**

```python
    def set(self, s, delay):
        s.timer_gen += 1
        heapq.heappush(self._heap, (time.monotonic() + delay, next(self._seq), s, s.timer_gen))
```

### `Timers.cancel`

**Зачем нужна:** Лениво отменяет таймер сессии: увеличивает поколение. Удалять старую запись из кучи сразу не нужно — она будет отброшена при просмотре.

**Код:**

```python
    @staticmethod
    def cancel(s):
        s.timer_gen += 1
```

### `Timers._discard_stale`

**Зачем нужна:** Удаляет с вершины кучи записи для закрытых сессий или неактуального поколения. Останавливается на первом действующем таймере, потому что он раньше остальных.

**Код:**

```python
    def _discard_stale(self):
        while self._heap:
            _, _, s, gen = self._heap[0]
            if s.closed or gen != s.timer_gen:
                heapq.heappop(self._heap)
            else:
                return
```

### `Timers.next_timeout`

**Зачем нужна:** Возвращает число секунд до ближайшего действующего таймера для передачи в select(). Если таймеров нет, возвращает None; если срок уже наступил — 0.

**Код:**

```python
    def next_timeout(self):
        """Сколько секунд ждать в select() (None — бесконечно)."""
        self._discard_stale()
        if not self._heap:
            return None
        return max(0.0, self._heap[0][0] - time.monotonic())
```

### `Timers.pop_expired`

**Зачем нужна:** Генератор сессий, чьи действующие таймеры уже истекли. Устаревшие записи пропускает, а актуальные снимает с кучи и выдаёт вызывающему коду.

**Код:**

```python
    def pop_expired(self):
        """Итератор по сессиям, чей таймер сработал."""
        now = time.monotonic()
        while self._heap and self._heap[0][0] <= now:
            _, _, s, gen = heapq.heappop(self._heap)
            if s.closed or gen != s.timer_gen:
                continue
            yield s
```
